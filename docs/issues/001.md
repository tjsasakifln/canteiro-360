Criar a base compilável do produto com Rust no servidor e na interface.

## Entregas desta etapa

- Workspace com crates de domínio, aplicação, persistência, contratos de API, web, servidor e processamento, conforme arquitetura.
- Fixar toolchain estável, Cargo.lock e versões compatíveis Leptos/Axum/Tokio/SQLx; compilar servidor e wasm32-unknown-unknown.
- Renderizar uma rota Leptos no servidor e hidratá-la; configuração de desenvolvimento e homologação com segredos externos.
- Pipeline de formatação, clippy, testes, build SSR/WASM, dependências e licenças; comando Rust xtask para validação do plano.

## Critérios de aceite verificáveis

- [ ] Checkout limpo compila ambos os alvos pelo procedimento documentado, sem servidor Node ou lógica JS/TS própria.
- [ ] HTML da rota contém conteúdo útil antes do WASM e interação funciona após hidratar, sem erro de divergência.
- [ ] Pipeline falha diante de teste quebrado, segredo de exemplo indevido ou mudança que introduza lógica de aplicação JS/TS.
- [ ] Registrar versões efetivamente compiladas e custo/tamanho inicial; não afirmar aplicação comercial a partir da tela inicial.

## Experiência exigida

Tela inicial sóbria com estados de carregamento e falha; não simular login ou transação que ainda não existe.
