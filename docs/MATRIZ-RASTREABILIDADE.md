# Matriz de rastreabilidade

Esta matriz liga requisito, origem documental, implementação e teste. O [registro completo em JSON](matriz.json) preserva a regra, a adaptação privada e o critério de aceite de cada ID. Para os grupos funcionais, a coluna ID abre a especificação completa. Os requisitos de produto estão detalhados em [experiência](experiencia.md) e [prontidão comercial](prontidao-comercial.md). Há **192 requisitos identificados**, todos com issue primária, fonte ou decisão, localização e aceite.

Origem Documentada identifica evidência externa; Adaptada identifica alteração explícita para o uso privado; Decisão identifica requisito próprio. Nenhuma dessas classificações declara software já implementado. A issue primária implementa o núcleo; cenários entre módulos posteriores são obrigatórios na issue 70 e na liberação 72.
